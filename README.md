Investigación – Modelos y Sistemas

¿De qué trata este trabajo?
Este trabajo es la primera parte de una investigación para la materia **Modelos y Sistemas**.

Temas incluidos (por ahora)
1. Diagrama de flujo de datos: cómo circula la información dentro de un sistema.
2. Diccionario de datos: descripción ordenada de cada dato que usa el sistema.
3. Diagrama entidad-relación: cómo se organizan y se relacionan los datos que se guardan.
4. Diagrama de transición de estados: los estados por los que pasa un elemento (por ejemplo, una herramienta prestada).
5. Prototipo: versión preliminar del sistema para validar ideas con el usuario.
6. Ciclo de vida del software: etapas y modelos de desarrollo (cascada, prototipos, espiral, iterativo).
7. Diseño de documentación y manuales: manual de usuario, manual técnico, técnicas y lineamientos para escribirlos.

Estructura del documento
- Portada
- Introducción
- Desarrollo
- Conclusión
- Referencias bibliográficas

Fuentes
