# Investigación – Modelos y Sistemas (7.º año)

## Primera parte: Herramientas de análisis y diseño de sistemas

### ¿De qué trata este trabajo?

Este trabajo es la primera parte de una investigación para la materia **Modelos y Sistemas**. Explica, con lenguaje simple y ejemplos, algunas de las herramientas que se usan para **analizar, diseñar y documentar** un sistema informático antes (y durante) su programación.

Como caso de ejemplo se usa el **Sistema de Gestión del Pañol Escolar**, el mismo proyecto que se trabajó en clase.

### Temas incluidos

De la lista completa del programa se eligieron siete temas, los más accesibles para una primera investigación:

1. **Diagrama de flujo de datos (DFD):** cómo circula la información dentro de un sistema.
2. **Diccionario de datos:** descripción ordenada de cada dato que usa el sistema.
3. **Diagrama entidad-relación (DER):** cómo se organizan y se relacionan los datos que se guardan.
4. **Diagrama de transición de estados:** los estados por los que pasa un elemento (por ejemplo, una herramienta prestada).
5. **Prototipo:** versión preliminar del sistema para validar ideas con el usuario.
6. **Ciclo de vida del software:** etapas y modelos de desarrollo (cascada, prototipos, espiral, iterativo).
7. **Diseño de documentación y manuales:** manual de usuario, manual técnico, técnicas y lineamientos para escribirlos.

### Estructura del documento

- Portada (con campos a completar: nombre, institución, docente)
- Introducción
- Desarrollo (un apartado por cada tema)
- Conclusión
- Referencias bibliográficas

### Normas utilizadas

Citas y referencias en **formato APA 7.ª edición**.
